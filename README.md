## What this is

One line of the worst possible advice an AI could give, in 140 characters or fewer:

> You can save money on passwords by using the same one everywhere. Easy to remember, easy to use.

Why this line: it is the kind of breezy, confident tip a real AI assistant would actually output. Reusing one password everywhere is genuinely terrible advice, specific enough to follow and regret, and the second sentence sells it like a feature. Short, tight, no wasted words.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the line to `/output/entry.txt`.

python3 main.py
